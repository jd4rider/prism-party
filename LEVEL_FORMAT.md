# Level format

`src/levels/campaign.js` is generated by `scripts/bake-levels.mjs`. Do not hand edit it;
change the generator and re-bake.

```js
export const LEVELS = [
  {
    id: 'w1-01',
    index: 1,              // 1-based position in the campaign
    world: 1,
    number: 1,             // position within the world
    width: 5,
    height: 5,
    seed: 100131,
    devices: [ /* see below */ ],
    initialRotations: { d2: 1, d4: 0 },   // the scrambled board the player starts on
    solution: { d2: 0, d4: 1 },           // the nearest solution, for reference and hints
    minMoves: 2,                          // turns needed for three stars
    solutionCount: 1,                     // how many configurations solve it
    difficulty: 1,                        // 1..5, derived from the board
    mechanics: ['mirror', 'receiver']     // sorted, for the UI and achievements
  }
]
```

## Devices

Every device has `id`, `type`, `x`, `y` and `rotation`.

```js
{ id: 'e1', type: 'emitter',  x: 0, y: 3, rotation: 1, color: 'white' }   // rotation = firing direction
{ id: 'd2', type: 'mirror',   x: 3, y: 3, rotation: 0, rotatable: true }
{ id: 'd3', type: 'prism',    x: 2, y: 1, rotation: 3, rotatable: true }
{ id: 'd4', type: 'filter',   x: 1, y: 2, rotation: 0, pass: 'red' }      // fixed filter
{ id: 'd5', type: 'filter',   x: 1, y: 2, rotation: 2, rotatable: true }  // cycles the six masks
{ id: 'd6', type: 'splitter', x: 2, y: 2, rotation: 0, rotatable: true }
{ id: 'r1', type: 'receiver', x: 4, y: 3, rotation: 0, required: 'blue', minIntensity: 0.4 }
{ id: 'pa', type: 'portal',   x: 2, y: 4, rotation: 0, pair: 'a' }
{ id: 'g1', type: 'gate',     x: 3, y: 3, rotation: 0, switchId: 'sw1' }
{ id: 'sw1', type: 'switch',  x: 5, y: 1, rotation: 0 }
{ id: 'c1', type: 'combiner', x: 3, y: 3, rotation: 0 }
{ id: 'b1', type: 'blocker',  x: 2, y: 2, rotation: 0 }
```

- `rotatable: true` puts the device under player control and adds it to the solver's
  state space. Anything without the flag is fixed.
- `serial` ids are not meaningful; only uniqueness within a level matters.
- `initialRotations` and `solution` only contain rotatable devices.

## Save data

`localStorage['prism-party-save-v1']`, version 3. Loading merges onto a fresh default so
missing or extra fields never break a save.

```js
{
  version: 3,
  levels: { 'w1-01': { stars: 3, bestMoves: 2, hints: 0, at: 1700000000000 } },
  achievements: { 'first-light': 1700000000000 },
  settings: { sound: true, music: false, reducedMotion: false, effects: true, highContrast: false, assist: true },
  daily: { date: '', stars: 0, moves: 0, streak: 0, lastDate: '' },
  stats: { solved: 0, moves: 0, hints: 0, perfect: 0, rotations: 0 },
  current: { levelId: 'w1-04', rotations: { d2: 1 }, moves: 1, hints: 0, at: 0 }
}
```
